# 😼 Simon Game
This digital game is created based on the physical Simon Game. This is my personal game project built using HTML, CSS, JavaScript, and JQuery. It showcases my logic, skills, and experience in web development and design.

## 👾 Technologies
- HTML
- CSS
- JQuery
- JavaScript 

## 👇 Features
- Fully responsive layout

## 🙌 How to play
Here's what you can do with Simon Game:
- Press the A key to start the game
- Watch and listen as the four buttons light up randomly and produce different sounds
- Click those four colours in the same order to progress to the next round
- With each round, the number of buttons to press increases as does the challenge

## 👩🏼‍🍳 The process
<p>I started by downloading the resources which included HTML and CSS files from the course I've studied on Udemy. Then, I focused on drawing the flowchart of the game before coding on VSCode.<br />

Next, I made sure users could use the key A to start the game, also showed an alert "Please press key A to start" just in case users forget. <br />

To make sure users know when the game is over, I implemented the red background features.</p>
